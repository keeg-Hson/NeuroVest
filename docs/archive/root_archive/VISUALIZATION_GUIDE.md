## 🎨 Usage

### Generate All Visualizations
```bash
python visualize.py
```

### Generate Specific Visualization
```bash
python visualize.py regime        # Economic regime detection
python visualize.py importance    # Feature importance
python visualize.py correlations  # Cross-asset relationships
python visualize.py indicators    # Economic timeline
python visualize.py drawdown      # Drawdown analysis
python visualize.py returns       # Cumulative returns
python visualize.py winrate       # Win rate analysis
```

### Location
All visualizations saved to: `visualizations/` directory

## 🎓 Pro Tips

1. **Always start with economic context** (indicators timeline)
2. **Show the "learning"** (feature importance, correlations)
3. **Demonstrate quality** (regime detection, model agreement)
4. **Validate with results** (returns, drawdown) - but not first!

5. **Export for presentations**:

   - Feature importance (top left)
