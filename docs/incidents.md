# Incident Log

Record production incidents, data quality issues, or model misbehavior here.
Format: `YYYY-MM-DD HH:MM UTC | severity | title | root cause | resolution | follow-up`.

Severity levels: **P0** (down/bad trades), **P1** (degraded), **P2** (minor).

---

## Template

```
## YYYY-MM-DD | P? | Short title

**Detected:** YYYY-MM-DD HH:MM UTC
**Resolved:** YYYY-MM-DD HH:MM UTC
**Duration:** X hours

**Symptom:** What was observed (e.g. pipeline failed, accuracy dropped, signals missing).

**Root cause:** Why it happened.

**Resolution:** What was done to fix it.

**Follow-up tasks:**
- [ ] Preventive measure 1
- [ ] Preventive measure 2
```
